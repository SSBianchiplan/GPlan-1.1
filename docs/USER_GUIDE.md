## Primeiro Acesso

### Fazendo Login

1. Acesse o sistema pelo navegador
2. Insira seu **email** e **senha**
3. Clique em **Entrar**

Se for seu primeiro acesso, você receberá as credenciais do administrador do sistema.

### Níveis de Acesso

O sistema possui 4 níveis de acesso:

- **ADMIN**: Acesso total ao sistema
- **MANAGER**: Gerenciamento de módulos e equipes
- **USER**: Operações do dia a dia
- **VIEWER**: Apenas visualização

## Dashboard

A página inicial mostra uma visão geral do sistema:

### Métricas Principais

- **Total de Produtos**: Quantidade total de produtos cadastrados
- **Estoque Baixo**: Produtos que precisam de reposição
- **Ordens Ativas**: Ordens de produção em andamento
- **Performance**: Indicador geral de eficiência

### Ações Rápidas

Use os cards de ações rápidas para:
- Criar nova ordem de produção
- Adicionar produto ao estoque
- Registrar movimentação de estoque

## Planejamento de Produção

### Visualizando Ordens de Produção

1. Clique em **Planejamento de Produção** no menu lateral
2. Use os filtros para ver ordens específicas:
   - **Todos**: Todas as ordens
   - **Pendente**: Aguardando início
   - **Em Andamento**: Em execução
   - **Concluído**: Finalizadas

### Status das Ordens

- **Pendente**: Ordem criada, aguardando início
- **Em Andamento**: Produção em execução
- **Concluído**: Produção finalizada
- **Cancelado**: Ordem cancelada

### Prioridades

- **URGENT** (Urgente): Vermelho - Prioridade máxima
- **HIGH** (Alta): Laranja - Alta prioridade
- **NORMAL** (Normal): Azul - Prioridade padrão
- **LOW** (Baixa): Cinza - Menor prioridade

### Criando uma Nova Ordem

1. Clique no botão **Nova Ordem**
2. Preencha os dados:
   - **Número da Ordem**: Código único (ex: OP-2024-001)
   - **Produto**: Selecione o produto
   - **Quantidade**: Quantidade a produzir
   - **Prioridade**: Defina a urgência
   - **Data Prevista**: Quando deve estar pronto
3. Clique em **Criar**

### Atualizando Status

Para atualizar o status de uma ordem:
1. Clique na ordem desejada
2. Selecione o novo status
3. Confirme a alteração

## Controle de Estoque

### Visualizando Produtos

1. Clique em **Controle de Estoque** no menu
2. Veja a lista de todos os produtos
3. Use a **barra de busca** para encontrar produtos específicos

### Indicadores de Estoque

Os produtos são identificados por cores:

- 🔴 **Baixo** (Vermelho): Estoque abaixo do mínimo
- 🟢 **Normal** (Verde): Estoque adequado
- 🟠 **Alto** (Laranja): Estoque acima do máximo

### Cadastrando um Novo Produto

1. Clique em **Novo Produto**
2. Preencha as informações:
   - **Código**: Código único do produto (ex: PROD-001)
   - **Nome**: Nome descritivo
   - **Categoria**: Classificação do produto
   - **Unidade**: Unidade de medida (UN, KG, L, etc.)
   - **Estoque Mínimo**: Quantidade mínima aceitável
   - **Estoque Máximo**: Quantidade máxima recomendada
   - **Preço Unitário**: Valor do produto
3. Clique em **Salvar**

### Registrando Movimentações

Para registrar entrada ou saída de estoque:

1. Clique em **Movimentação**
2. Selecione o **Produto**
3. Escolha o **Tipo de Movimentação**:
   - **IN** (Entrada): Chegou produto
   - **OUT** (Saída): Produto foi usado/vendido
   - **ADJUSTMENT** (Ajuste): Correção de estoque
   - **TRANSFER** (Transferência): Entre locais
4. Informe a **Quantidade**
5. Adicione uma **Referência** (ex: número da nota fiscal)
6. Adicione **Observações** se necessário
7. Clique em **Registrar**

### Alertas de Estoque

O sistema alerta automaticamente quando:
- Estoque fica abaixo do mínimo
- Produtos precisam de reposição
- Estoque ultrapassa o máximo

## Perfil e Configurações

### Visualizando seu Perfil

### Saindo do Sistema

1. Clique no ícone de **Sair** no canto superior direito

## Dicas de Uso

### ✅ Boas Práticas

1. **Mantenha o estoque atualizado**: Registre todas as movimentações
2. **Use prioridades corretamente**: Reserve "URGENT" para casos realmente urgentes
3. **Complete ordens no prazo**: Atualize o status conforme o andamento
4. **Cadastre produtos completos**: Preencha todas as informações relevantes
5. **Use referências nas movimentações**: Facilita a rastreabilidade

### 🔍 Recursos de Busca

- Use a busca por código ou nome de produto
- Filtre ordens por status e prioridade
- Ordene tabelas clicando nos cabeçalhos

### 📱 Responsividade

O sistema funciona em:
- Computadores desktop
- Tablets
- Smartphones

## Perguntas Frequentes

### Como altero minha senha?

Contate o administrador do sistema para solicitar alteração de senha.

### Não consigo criar uma ordem de produção

Verifique se você tem permissão de **USER**, **MANAGER** ou **ADMIN**. Usuários com permissão **VIEWER** só podem visualizar.

### O estoque não está atualizando

Certifique-se de que está registrando as movimentações corretamente. Verifique o tipo de movimentação selecionado.

### Posso deletar um produto?

Produtos não podem ser deletados, mas podem ser marcados como **inativos** por um administrador.

### Como exporto relatórios?

A funcionalidade de exportação de relatórios estará disponível em breve. Por enquanto, você pode copiar os dados das tabelas.

### Esqueci minha senha

Contate o administrador do sistema para resetar sua senha.

### O sistema está lento

- Verifique sua conexão com a internet
- Limpe o cache do navegador
- Contate o suporte técnico se o problema persistir
