# Guia do Usuário - GPlan

## Introdução

O GPlan é um sistema integrado de planejamento e gestão empresarial que oferece funcionalidades completas para gerenciar diferentes aspectos do seu negócio.

## Acesso ao Sistema

1. Acesse o sistema através do navegador web
2. Faça login com suas credenciais
3. Você será direcionado à tela principal (Home)

## Navegação

### Barra de Navegação Superior

A barra de navegação no topo da página permite acesso rápido a todos os módulos:

- **Início**: Retorna à tela principal
- **Planejamento Financeiro**: Acessa o módulo financeiro
- **Estoque**: Gerenciamento de produtos
- **Auditorias**: Relatórios e auditorias
- **Pedidos**: Gestão de compras e vendas

### Ícones da Barra de Navegação

- **🔍 Busca**: Abre campo de busca global para encontrar funcionalidades rapidamente
- **🔔 Notificações**: Visualiza notificações importantes do sistema
- **👤 Usuário**: Acesso ao perfil e configurações

## Tela Principal (Home)

### Indicadores Rápidos

Na parte superior da Home, você encontra 4 cards com indicadores principais:

1. **Receita Total**: Valor total de receitas
2. **Pedidos Ativos**: Número de pedidos em andamento
3. **Produtos**: Quantidade total de produtos no estoque
4. **Usuários Ativos**: Número de usuários online

### Módulos do Sistema

Cards interativos que dão acesso aos principais módulos:

- **Planejamento Financeiro**: Com estatísticas de receita mensal e meta atingida
- **Controle de Estoque**: Exibe número de produtos e alertas de estoque baixo
- **Auditorias**: Mostra auditorias realizadas e pendentes
- **Pedidos**: Apresenta pedidos ativos e novos do dia

### Painel de Notificações

No lado direito, você encontra as notificações recentes:

- ⚠️ Avisos importantes
- ✓ Confirmações de ações
- ℹ️ Informações gerais
- ❌ Alertas críticos

## Módulo: Planejamento Financeiro

### Visão Geral

O módulo de Planejamento Financeiro oferece análise completa do desempenho financeiro da empresa.

### Cartões de Resumo

4 cartões no topo exibem:

1. **Total Planejado**: Soma dos valores planejados para o ano
2. **Total Realizado**: Soma dos valores efetivamente realizados
3. **Taxa de Atingimento**: Percentual de realização vs planejamento
4. **Variação**: Diferença absoluta entre realizado e planejado

### Gráficos Interativos

#### Evolução Mensal (Gráfico de Linha)
- Mostra a evolução mês a mês
- Linha azul: Valores planejados
- Linha verde: Valores realizados
- Passe o mouse sobre os pontos para ver valores detalhados

#### Comparação por Mês (Gráfico de Barras)
- Compara lado a lado os valores de cada mês
- Barras azuis: Planejado
- Barras verdes: Realizado
- Facilita identificar meses com maior variação

### Comparação de Metas

Seção que detalha o progresso de cada meta financeira:

- **Barra de Progresso**: Visual do percentual atingido
- **Cores da Barra**:
  - 🟢 Verde: Meta atingida (100%+)
  - 🔵 Azul: Boa performance (75-99%)
  - 🟡 Amarelo: Atenção necessária (50-74%)
  - 🔴 Vermelho: Abaixo do esperado (<50%)

- **Informações Detalhadas**:
  - Valor planejado
  - Valor realizado
  - Percentual de atingimento
  - Quanto falta para atingir a meta

### Exportação de Relatórios

#### Exportar PDF
1. Clique no botão "Exportar PDF"
2. O relatório será gerado automaticamente
3. Inclui:
   - Tabela com dados mensais
   - Resumo financeiro
   - Data de geração

#### Exportar Excel
1. Clique no botão "Exportar Excel"
2. O arquivo será baixado automaticamente
3. Contém duas planilhas:
   - **Relatório Financeiro**: Dados mensais detalhados
   - **Resumo**: Totalizações e indicadores

## Busca Global

1. Clique no ícone de busca (🔍) na barra de navegação
2. Digite o termo que deseja buscar
3. O sistema buscará em:
   - Funcionalidades
   - Relatórios
   - Dados do sistema
4. Clique no resultado desejado para acessar

## Dicas de Uso

### Navegação Rápida
- Use a tecla **Tab** para navegar entre elementos
- Use **Enter** para selecionar/ativar elementos
- A busca global (Ctrl+K) oferece acesso rápido

### Visualização de Gráficos
- Passe o mouse sobre os gráficos para ver detalhes
- Clique nas legendas para ocultar/mostrar séries
- Os gráficos são responsivos e se adaptam ao tamanho da tela

### Notificações
- Notificações importantes aparecem com destaque
- Clique em "Ver todas as notificações" para histórico completo
- Notificações críticas aparecem em vermelho

### Exportação
- Sempre verifique os dados antes de exportar
- Relatórios PDF são ideais para impressão
- Excel permite análise adicional dos dados
